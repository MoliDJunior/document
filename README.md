# Laboratorio de Aprendizaje y Documentación Tecnológica

¡Bienvenido a este **Laboratorio de Aprendizaje**! Este espacio es un proyecto personal diseñado para explorar, experimentar y documentar de manera propia el entendimiento sobre diversas tecnologías del desarrollo de software.

La filosofía del proyecto es simple: **aprender haciendo, registrar conceptos clave en palabras sencillas (¡y con humor!) y tener una referencia rápida de estudio.**

---

## Tecnologías en el Laboratorio

Actualmente, el laboratorio cuenta con apuntes y resúmenes prácticos sobre las siguientes tecnologías:

| Tecnología | Estado        | Descripción del Contenido                                                                                                 |
| :--------- | :------------ | :------------------------------------------------------------------------------------------------------------------------ |
| **HTML5**  | Activo        | Conceptos fundamentales, sintaxis de etiquetas, tablas, formularios y estructura semántica básica ("HTML en 5 segundos"). |
| **CSS3**   | En progreso   | Propiedades esenciales de diseño, colores de fondo, tipografías y el uso integrado del framework **Bootstrap**.           |
| **C#**     | Activo        | Paradigmas de programación, con enfoque en la programación orientada a objetos (POO), clases y atributos.                 |
| **Python** | En desarrollo | Espacio reservado para las bases de programación en Python, lógica de control y scripts.                                  |

---

## Estructura del Proyecto

El laboratorio está organizado de forma modular para separar la interfaz del contenido de aprendizaje:

```text
├── assets/          # Recursos visuales e imágenes representativas de cada tecnología.
├── css/             # Estilos de la aplicación.
│   ├── style.css             # Hoja de estilos principal del proyecto.
│   ├── bootstrap.min.css     # Framework para un diseño ágil y responsivo.
│   ├── bootstrap.bundle.min.js
│   └── [tecnologia].css      # Estilos personalizados para cada sección tecnológica.
├── html/            # Documentación interactiva.
│   ├── index.html            # Portal de inicio y menú central de navegación.
│   ├── html.html             # Guía exprés de etiquetas HTML.
│   ├── css.html              # Apuntes y selectores de CSS.
│   ├── cshar.html            # Conceptos de programación con C#.
│   └── python.html           # Bases del lenguaje Python.
└── README.md        # Esta documentación.
```

## Filosofía y Estilo

A diferencia de las documentaciones técnicas aburridas y densas, este laboratorio adopta un **estilo informal, dinámico y humorístico**. Explicar los conceptos complejos con analogías cotidianas, bromas internas y palabras directas ayuda a fijar el conocimiento y hace que repasar sea entretenido.

> _“Si no puedes explicarlo de forma sencilla (o con un buen meme), es que aún no lo has entendido lo suficiente.”_
